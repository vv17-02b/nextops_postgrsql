# ShopWorld Walk — Frontend 🛍️

Фронтенд-частина платформи електронної комерції **ShopWorld Walk**, побудована на базі сучасного фреймворку Next.js 15. Працює в єдиному монорепозиторії разом із бекенд-сервісами через Yarn Workspaces.

## 🚀 Технологічний стек

- **Фреймворк:** [Next.js 15](https://nextjs.org) (App Router, React 19)
- **Менеджер пакетів:** Yarn v1.22.22 (Yarn Workspaces)
- **Мова програмування:** TypeScript
- **Стилізація:** Tailwind CSS (або ваш варіант, за потреби змініть)

## 📁 Ключові маршрути та сторінки (Routes)

Додаток реалізує наступну структуру сторінок:

- `/` — Головна сторінка платформи.
- `/store` — Вітрина магазину (каталог товарів, інтегрований із базою даних, виведення зображень та знижок).
- `/login` — Сторінка авторизації користувачів.
- `/register` — Реєстрація нових клієнтів (створення профілю, оформлення підписки та бонусного рахунку).
- `/profile` — Особистий кабінет (історія замовлень, статус підписки, накопичені бонуси).
- `/client` — Спеціалізована клієнтська зона / панель керування.

## 🛠️ Швидкий старт для розробки

Оскільки проєкт є частиною монорепозиторію, запуск зазвичай виконується з кореневої папки проєкту за допомогою `concurrently`.

### Запуск з кореню репозиторію:
```bash
# Запуск фронтенду та бекенду одночасно
yarn dev
```

### Запуск окремо з папки frontend:
Якщо ви перебуваєте безпосередньо в директорії `frontend/`, виконайте:
```bash
yarn next dev
```
Фронтенд буде доступний за адресою: [http://localhost:3000](http://localhost:3000)

## 📡 Інтеграція з API

Фронтенд взаємодіє з сервером розробки:
- **API URL:** `http://localhost:5000` (Production домен: `https://shopworld-walk.com`)
- **База даних:** Здійснює непряму взаємодію через бекенд та Prisma ORM (PostgreSQL) для отримання даних користувачів, підписок (`Subscription`), бонусів (`BonusAccount`) та товарів (`Product`, `ProductImage`, `Discount`).

## 🧱 Скрипти

- `yarn dev` — Запуск сервера розробки Next.js.
- `yarn build` — Збирання оптимізованого проєкту для production.
- `yarn start` — Запуск зібраного production-додатка.
- `yarn lint` — Перевірка коду лінтером.
