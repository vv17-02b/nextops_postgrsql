📋 ДОВІДНИК NODE.JS: ГЛОБАЛЬНІ ОБ'ЄКТИ, АРГУМЕНТИ ТА МОДУЛІ
========================================================================

1. ГЛОБАЛЬНІ ОБ'ЄКТИ ТА ЗМІННІ (Global Objects)
Доступні в будь-якому файлі автоматично без require() чи import.

• global      - Головний глобальний об'єкт (аналог window у браузері).
• __dirname   - Повний абсолютний шлях до папки, де лежить поточний файл.
• __filename  - Повний абсолютний шлях разом із назвою поточного файлу.
• process     - Об'єкт для керування поточним процесом Node.js.
• console     - Інструмент для виведення логів (log, error, table, time).
• setTimeout / setInterval - Функції для створення таймерів та затримок.

------------------------------------------------------------------------
2. ОБ'ЄКТ PROCESS (Управління процесом та аргументи)
Дає контроль над програмою, яка виконується в терміналі.

• process.argv     - Масив аргументів командного рядка.
                     [0] - шлях до node.exe
                     [1] - шлях до JS-файлу
                     [2] і далі - ваші кастомні аргументи.
• process.env      - Об'єкт зі змінними оточення (наприклад, секретні ключі).
• process.exit()   - Примусове завершення програми (0 - успіх, 1 - помилка).
• process.cwd()    - Повертає шлях до папки, з якої БУЛО ЗАПУЩЕНО команду.

------------------------------------------------------------------------
3. ГОЛОВНІ ВБУДОВАНІ МОДУЛІ (Core Modules)
Потребують підключення на початку файлу: const mod = require('mod').

📂 Модуль 'fs' (File System) — Робота з файлами та папками:
• fs.writeFile(path, data, callback) - Перезаписує або створює файл.
• fs.appendFile(path, data, callback)- Додає текст у кінець файлу.
• fs.readFile(path, encoding, cb)    - Зчитує вміст файлу.
• fs.mkdir(path, callback)           - Створює нову папку.
• fs.readdir(path, callback)         - Повертає список файлів у папці.
• fs.unlink(path, callback)          - Видаляє файл.

🗺️ Модуль 'path' — Робота зі шляхами:
• path.resolve(...paths) - Збирає правильний абсолютний шлях.
• path.join(...paths)    - Склеює шматочки шляху разом.
• path.extname(path)     - Повертає розширення файлу (наприклад, .js).
• path.basename(path)    - Повертає лише назву файлу з розширенням.

🌐 Модуль 'http' / 'https' — Мережа та сервери:
• http.createServer(cb)  - Створює вебсервер для обробки HTTP-запитів.

💻 Модуль 'os' — Інформація про операційну систему:
• os.platform()          - Тип ОС (win32, darwin, linux).
• os.cpus()              - Дані про процесор та кількість ядер.
• os.totalmem()          - Загальний обсяг оперативної пам'яті.

------------------------------------------------------------------------
4. ОСНОВНІ КОМАНДИ NODE.JS У ТЕРМІНАЛІ (CLI)

• node файл.js           - Запустити конкретний JS-файл.
• node                   - Відкрити інтерактивний режим REPL (вихід: Ctrl+C двічі).
• node -v                - Перевірити встановлену версію Node.js.
• node --watch файл.js   - Запустити файл у режимі автоперезапуску при змінах.
• node --env-file=.env f.js - Запустити файл з автоматичним імпортом .env файлу.
